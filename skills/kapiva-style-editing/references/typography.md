## 3. "Bold and slimmer" / "bold and light" (approved 2026-11-05)
When the user says it: two lines, ALL CAPS, white, centred, leading 0.95.
Top **Jost Bold 700** (~124 px on 1080-wide), tracking -0.01em. Bottom **Jost Light 300** (~70 px).
Soft drop shadow 4px 5px 6px 45% black. Variants: lime top line, or left-aligned.
Reference: `/Users/sajid.ali/Documents/Claude/Kapiva BPXJ – Sonia/hook1/two-line options/` (option A).
Use only when asked; never swap supers that are already approved.

## 4. Always
- Drop shadow on all text. Supers are the exact script words (on-screen text column), no extras.
- Kapiva health wording: "helps manage / supports / may help"; never "cures" (see brand module).
