# Video editing skills

Claude skills for editing reels and ads in Premiere Pro + After Effects, in my Kapiva house style.

## Start here
`skills/kapiva-style-editing/` — the all-in-one skill (merges all the others). Start a session with `/kapiva-style-editing`.

## All skills
| Skill | What it does |
|---|---|
| kapiva-style-editing | All-in-one: workflow, house style, typography, Premiere native text, previews |
| video-studio | Hub + `house-style.md` (standing rules) |
| premiere-pro-mcp | Premiere MCP bridge setup and troubleshooting |
| brand-kapiva | Kapiva colours, logo, health-claim wording |
| video-auto-editor | Hands-off edit: drop videos → storyboard → final MP4 |
| google-flow | AI B-roll prompts (Google Flow / Veo) |
| motion-broll | Word-timed UI motion B-roll |
| cut-silences / cut-mistakes | Whisper-based silence and mistake cutting |
| ae-builder | Rebuild animations as editable AE projects |
| video-idea-finder / reel-script-writer | Ideas and reel scripts |

`PROJECT-INSTRUCTIONS.md` — standing rules to paste into a claude.ai Project.

## Install
Copy a folder from `skills/` to `~/.claude/skills/` (Claude Code), or zip it and upload on claude.ai → Settings → Capabilities → Skills.
Premiere/AE control needs the MCP bridge on that Mac.
